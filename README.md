# 泰语日课

适配手机、平板和电脑的中文泰语学习渐进式网页应用（PWA）。包括短句课程、浏览器泰语语音、选择回忆、声调提示、学习进度保存和离线缓存。

## 预览与安装

用任意静态文件服务器托管本目录即可。访问部署网址后，可通过浏览器的“添加到主屏幕”安装到 iPhone/iPad 或 Android 设备。HTTPS 是安装和离线功能的要求。

仓库已包含 GitHub Pages 自动部署工作流。创建 GitHub 仓库并把本目录推送到 `main` 分支后，在仓库 Settings → Pages 中把部署来源设为 GitHub Actions；之后每次推送都会自动更新网站。

学习记录目前存储在当前浏览器的本地设备中。语音由设备浏览器的泰语语音引擎合成，实际语音与可用性依设备而异。Google Fonts 字体需要联网，应用其余页面资源会在首次访问后缓存。
